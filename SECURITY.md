# Security Policy

## Supported Versions

The following versions of **Legal-GPT** currently receive security updates:

| Version | Supported          |
| ------- | ------------------ |
| 0.2.x   | :white_check_mark: |
| < 0.2.0 | :x:                |

---

## Reporting a Vulnerability or Security Incident

We take the security and privacy of this public legal intelligence project seriously.

If you discover:
- A potential security vulnerability in the codebase or APIs,
- An exposed credential, API key, or authentication token,
- An accidental inclusion of non-public, proprietary, or personal identifying information (PII),

**Please DO NOT open a public issue.**

Instead, report the issue immediately by contacting repository maintainers via GitHub Private Vulnerability Reporting or via private email:
- **Email**: `security@legal-gpt.org` (or directly through GitHub repository security advisory features).

---

## Public Repository Privacy Commitment

Legal-GPT is an open-source legal research and intelligence tool. It operates exclusively with:
- Publicly available federal and state statutes
- Published appellate judicial opinions
- Public administrative agency regulations and policies
- Synthetic, anonymized benchmark fixtures

Under our [Public Data Policy](PUBLIC_DATA_POLICY.md), no private legal case files, evidence data, or personal information may be stored or committed to this repository.
